5. Mesh-based learned simulators and hybrid solvers

Instead of learning a global map, these methods learn a local update rule on the simulation mesh and apply it repeatedly, or they keep a numerical solver and learn a correction to it.

5.1 MeshGraphNets

MeshGraphNets learn the time step \(u(t)\mapsto u(t+\Delta t)\) with message passing on the simulation mesh in an encode–process–decode architecture. Each processing layer updates edges and then nodes, \[ e'_{ij} = f_e(e_{ij}, v_i, v_j), \qquad v'_i = f_v\Big(v_i, \sum_j e'_{ij}\Big). \] Training uses one-step targets with noise injection so that long rollouts stay stable, and the method supports adaptive remeshing. It handles unstructured meshes and varying geometry naturally. The limitations are error accumulation over long rollouts and the limited receptive field of local message passing: effects that are global, such as pressure in incompressible flow, need many layers or multiscale graphs.

Papers
  • T. Pfaff, M. Fortunato, A. Sanchez-Gonzalez, P. W. Battaglia, Learning mesh-based simulation with graph networks, ICLR, 2021.

5.2 Message passing neural PDE solvers

This work studies what it takes to make message-passing solvers stable and general: the pushforward trick (training on the model's own perturbed predictions to reduce distribution shift in rollouts), temporal bundling (predicting several future steps at once), and conditioning on PDE parameters so that one model covers a family of equations.

Papers
  • J. Brandstetter, D. Worrall, M. Welling, Message passing neural PDE solvers, ICLR, 2022.

5.3 Learned corrections inside a numerical solver

Keep a differentiable CFD solver at coarse resolution and learn the parts it gets wrong. In the paper by Kochkov and coauthors, a convolutional network supplies learned interpolation coefficients inside a finite-volume scheme for 2D turbulence, trained end to end by unrolling the solver so that coarse simulations track downsampled high-resolution ones. Because the solver's structure (conservation, time stepping) is kept, these models tend to be more stable and generalize better than pure surrogates. They require a differentiable solver, and the paper treats periodic 2D domains. The analogous idea in reduced-order modeling is closure modeling for POD-Galerkin ROMs.

Papers
  • D. Kochkov, J. A. Smith, A. Alieva, Q. Wang, M. P. Brenner, S. Hoyer, Machine learning–accelerated computational fluid dynamics, PNAS, 2021.
