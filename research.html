Current directions

Research themes

  • Finite element methods: fitted and unfitted discretizations for PDEs on complex, moving, and evolving domains.
  • Computational fluid dynamics: numerical methods for the Navier–Stokes equations, Shallow Water Equations, and coupled or multiphysics PDE systems.
  • Reduced-order modeling: Proper Orthogonal Decomposition (POD), Reduced Order Models (ROMs), and related data-driven reduction techniques.
  • Scientific machine learning: machine learning for fluid dynamics, data-driven modeling of dynamical systems, and efficient surrogate models for PDE simulations.

Software to explore

Scientific computing tools

Finite element methods

  • FEniCSx — a Python-friendly platform for automated finite element methods.
  • deal.II — a comprehensive C++ finite element library with extensive tutorials.
  • Netgen/NGSolve — high-performance multiphysics finite element software with Python and C++ interfaces.

Linear algebra and solvers

  • PETSc — scalable parallel solvers, preconditioners, and scientific-computing data structures.
  • Trilinos — a collection of C++ packages for linear algebra, nonlinear solvers, and optimization.
  • Eigen — a lightweight C++ library for dense and sparse linear algebra.

Reduced-order modeling

  • pyMOR — a Python library for model-order reduction with multiple solver backends.
  • Pressio — an ecosystem for projection-based reduced-order modeling of large-scale dynamical systems.
  • ITHACA-FV — reduced-order modeling tools for OpenFOAM simulations.
